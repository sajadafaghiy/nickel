# نیکل

[![Deploy Astro to GitHub Pages](https://github.com/sajadafaghiy/nickel/actions/workflows/deploy.yml/badge.svg)](https://github.com/sajadafaghiy/nickel/actions/workflows/deploy.yml)

نیکل یک وب‌سایت استاتیک فارسی و راست‌به‌چپ برای انتشار خلاصهٔ کتاب است که با Astro 7 ساخته شده است. کتاب‌ها و نویسندگان در قالب Markdown نگهداری می‌شوند؛ بنابراین برای افزودن محتوا نیازی به ویرایش صفحه‌ها یا کامپوننت‌ها نیست.

## امکانات

- صفحهٔ اختصاصی برای هر کتاب و نویسنده
- دسته‌بندی کتاب‌ها با برچسب‌ها
- جست‌وجو در عنوان، نویسنده، برچسب، توضیحات و متن کتاب
- بخش خلاصه‌های منتخب با اسلایدر واکنش‌گرا
- محاسبهٔ خودکار زمان مطالعه
- اشتراک‌گذاری کتاب و کپی متن در کلیپ‌بورد به‌عنوان جایگزین
- ذخیرهٔ آخرین کتاب و موقعیت مطالعه در مرورگر
- نمایش «ادامهٔ مطالعه» فقط در صفحهٔ اصلی و بازیابی موقعیت قبلی
- حذف پیشنهاد ادامهٔ مطالعه پس از رسیدن به انتهای کتاب یا بستن پیشنهاد
- پوستهٔ روشن و تیره با ذخیرهٔ انتخاب کاربر
- پشتیبانی از PWA و Service Worker
- خروجی کاملاً استاتیک و قابل انتشار در GitHub Pages

## پیش‌نیازها

- Node.js سازگار با Astro 7
- npm

## اجرای محلی

```bash
npm install
npm run dev
```

سپس نشانی نمایش‌داده‌شده در ترمینال، معمولاً `http://localhost:4321`، را باز کنید.

## افزودن نویسنده

ابتدا برای نویسنده یک فایل با نام انگلیسی در `src/content/authors/` بسازید. برای مثال، فایل `james-clear.md`:

```md
---
name: جیمز کلیر
---
```

نام فایل شناسهٔ نویسنده است و هنگام تعریف کتاب در فیلد `authors` استفاده می‌شود.

## افزودن خلاصهٔ تازه

یک فایل با نام انگلیسی و پسوند `.md` در `src/content/books/` بسازید:

```md
---
title: نام کتاب
emoji: 📘
authors:
	- james-clear
description: توضیح کوتاه برای کارت کتاب و موتورهای جست‌وجو
publishedAt: 2026-09-25
tags:
	- توسعه فردی
	- عادت‌ها
featured: false
draft: false
---

## ایدهٔ اصلی

متن خلاصه را اینجا بنویسید.
```

نکات مربوط به محتوا:

- نام فایل، نشانی صفحه را می‌سازد؛ برای مثال `my-book.md` به `/books/my-book/` تبدیل می‌شود.
- عنوان را بدون گیومهٔ فارسی `« »` وارد کنید؛ گیومه‌ها در کارت‌های کتاب به‌صورت خودکار اضافه می‌شوند.
- مقدار `authors` باید آرایه‌ای از شناسه‌های موجود در `src/content/authors/` باشد.
- مقدار `emoji` الزامی است.
- مقدار `tags` اختیاری است و به‌صورت پیش‌فرض آرایه‌ای خالی خواهد بود.
- با `featured: true` کتاب در بخش خلاصه‌های منتخب نمایش داده می‌شود.
- با `draft: true` کتاب در خروجی سایت نمایش داده نمی‌شود.
- تاریخ باید به شکل `YYYY-MM-DD` باشد.

## فرمان‌های پروژه

| فرمان | کاربرد |
| --- | --- |
| `npm run dev` | اجرای سرور توسعه |
| `npm run build` | ساخت خروجی استاتیک |
| `npm run preview` | پیش‌نمایش خروجی ساخته‌شده |
| `npm run astro` | اجرای مستقیم CLI استرو |

خروجی نهایی در پوشهٔ `dist/` ساخته می‌شود.

## انتشار در GitHub Pages

1. پروژه را در یک مخزن GitHub قرار دهید و شاخهٔ اصلی را `main` بنامید.
2. در GitHub به **Settings → Pages** بروید.
3. زیر **Build and deployment**، گزینهٔ **Source** را روی **GitHub Actions** بگذارید.
4. پروژه را push کنید. گردش‌کار `.github/workflows/deploy.yml` سایت را می‌سازد و منتشر می‌کند.

پیکربندی Astro از متغیرهای محیطی زیر پشتیبانی می‌کند:

- `SITE_URL`: نشانی اصلی سایت
- `BASE_PATH`: مسیر پایه، مانند `/nickel/`

اگر این متغیرها تنظیم نشوند، مقادیر پیش‌فرض `https://username.github.io` و `/` استفاده می‌شوند.

## ذخیره‌سازی در مرورگر

این پروژه برای امکانات سمت کاربر از فضای ذخیره‌سازی مرورگر استفاده می‌کند:

- انتخاب پوسته در `localStorage`
- آخرین کتاب و میزان پیشرفت مطالعه در `localStorage`
- موقعیت موقت موردنیاز برای بازگشت به محل مطالعه در `sessionStorage`

هیچ‌یک از این اطلاعات به سرور ارسال نمی‌شوند. بستن پیشنهاد «ادامهٔ مطالعه» سابقهٔ ذخیره‌شده را حذف می‌کند و کتاب‌های تقریباً تمام‌شده نیز به‌صورت خودکار از سابقه حذف می‌شوند.

## ساختار مهم پروژه

- `src/content/books/`: خلاصه‌های کتاب در قالب Markdown
- `src/content/authors/`: اطلاعات نویسندگان در قالب Markdown
- `src/content.config.ts`: طرح و اعتبارسنجی مجموعه‌های محتوا
- `src/pages/`: صفحهٔ اصلی و مسیرهای کتاب، نویسنده و برچسب
- `src/layouts/BaseLayout.astro`: قالب اصلی، جست‌وجو، پوسته و ادامهٔ مطالعه
- `src/styles/global.css`: ظاهر فارسی، RTL و طراحی واکنش‌گرا
- `public/manifest.webmanifest`: تنظیمات PWA
- `public/sw.js`: Service Worker
- `.github/workflows/deploy.yml`: انتشار خودکار در GitHub Pages
